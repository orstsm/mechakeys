# MechaKeys 2.11.1 — community build

**Not notarized by Apple.** This free community build is ad-hoc signed, not Developer ID-signed. macOS may warn or block first launch, and updates may require Input Monitoring approval again. Only install if you trust this project. Never disable Gatekeeper or other system-wide security protections. Managed Macs may restrict installation.

## Download and install

Download **MechaKeys-2.11.1-universal-community.zip**, unzip it, and move MechaKeys.app into Applications. This is the ready-to-use app; GitHub's automatic “Source code” archives are not installers. Apple Silicon and Intel are supported; macOS 13 or newer is required. Allow Input Monitoring in Privacy & Security to enable keyboard sounds.

## Features

- Native notch controls, with optional menu-bar access.
- Default, K Pro Red and Alpaca recorded sound profiles, volume controls and spatial panning.
- Automatic pause for connected Bluetooth audio devices and resume when disconnected, respecting the manual sound preference.
- Event-driven hover and 30-second idle audio suspension.
- Manual update checks and optional daily checks, off by default. Checks contact GitHub only; no typed text, input events or analytics are sent. Installation remains manual.
- Updated About with accurate profile capabilities, community-build notice and **Built by orstsm** credit.
- Maintainer release workflow: pushing a matching version tag from GitHub Desktop runs tests and publishes a verified universal community ZIP with installation instructions and checksums.

Users on versions before 2.11.0 need a manual download to get update-check support. No exact battery-life savings are claimed. Developer ID signing and Apple notarization are not included.
