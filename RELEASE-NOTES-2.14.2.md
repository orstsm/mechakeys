# MechaKeys 2.14.2

- Reopening MechaKeys from Finder shows an independent controls window in either mode, even when the menu-bar icon or island is inaccessible.
- Launching in menu-bar mode and switching to that mode show the controls window, so a hidden or crowded status item cannot strand the user.
- Use an explicitly sized template menu-bar icon with a text fallback.
- Includes 2.14.1 sleep recovery, audio-exception protection, and native menu-bar lifecycle fixes. A previously running older process must exit before these fixes take effect.
